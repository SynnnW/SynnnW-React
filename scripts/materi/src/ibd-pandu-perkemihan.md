### Instruksi Pengerjaan LKP

Petunjuk Lengkap Penyelesaian Lembar Kerja Praktikum Mahasiswa

Mata Kuliah: Ilmu Biomedik Dasar Materi: Sistem Perkemihan

### Langkah-langkah Pengerjaan

1 Pelajari Modul Utama

Buka file MODUL PERKEMIHAN.pdf. Baca dan pahami seluruh landasan teori mengenai Anatomi dan Fisiologi Sistem Perkemihan (ginjal, ureter, vesika urinaria, uretra, serta mekanisme pembentukan urine).

2 Pemisahan LKP (Potong PDF Online)

Pisahkan bagian Lembar Kerja Praktikum (LKP) di bagian akhir modul menggunakan alat potong PDF online

(seperti iLovePDF atau Smallpdf).

Akses situs pemotong PDF (contoh: ilovepdf.com/split_pdf).

Unggah file MODUL PERKEMIHAN.pdf lalu pilih halaman LKP (Halaman 12–13).

Unduh file PDF yang telah dipisah.

3 Konversi ke Word & Setting Identitas

Konversikan file LKP PDF tersebut ke format Microsoft Word (.docx). Wajib mencantumkan identitas diri di

Pojok Kanan Atas lembar kerja:



Kelas Praktikum : [D1 / D2]

Panduan Pengerjaan LKP - Ilmu Biomedik Dasar Halaman 1 dari 2

4 Pengisian & Ketentuan Menggambar

Isi seluruh tabel identifikasi organ, fungsi, link video, dan komposisi urine normal.

Ketentuan Khusus Gambar: Skema/gambar proses disarankan kuat oleh PJMK untuk dibuat secara manual (tulis tangan / digambar tangan) di kertas, lalu difoto/discan dan dimasukkan ke dokumen

Word.

Pembuatan skema langsung di Word diperbolehkan, tetapi gambar manual lebih direkomendasikan.

5 Konversi Kembali ke PDF & Format Penamaan

Setelah selesai dikerjakan dan diperiksa, simpan file Word kembali ke format PDF (Export to PDF) dengan penamaan standar berikut:

Nama_NIM_Kelas

Contoh: BudiSantoso_231101001_D1.pdf

6 Pengumpulan Tugas

Unggah file PDF ke folder Google Drive yang telah disediakan oleh Co-Tugas sesuai dengan jadwal kelas masing-masing.

### Jadwal Pengumpulan Tugas
