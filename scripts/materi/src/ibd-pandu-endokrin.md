### Langkah 1

Buka Modul LKP Sistem Endokrin

Akses dan buka dokumen modul LKP Sistem Endokrin yang telah disediakan melalui perangkat komputer atau laptop Anda.

### Langkah 2

Pisahkan / Potong Lembar LKP

Pisahkan halaman LKP dari bagian modul utama. Gunakan fitur Extract atau Split PDF (misalnya menggunakan tools online/offline seperti Smallpdf, iLovePDF, atau Adobe Acrobat) untuk mengambil halaman LKP saja agar terpisah dari materi modul.

### Langkah 3

Salin dan Kerjakan di Microsoft Word

- Salin teks atau format LKP yang sudah dipisahkan ke dalam aplikasi Microsoft Word.

- Identitas Diri: Ketik Nama , NIM , dan Kelas di diletakkan pada bagian pojok kiri atas lembar LKP.

- Jawab seluruh pertanyaan, tabel pengamatan, atau tugas analisis pada LKP secara cermat, lengkap, dan sistematis.

### Langkah 4

Konversi Dokumen ke Format PDF

- Setelah selesai mengerjakan dan memeriksa ulang seluruh jawaban, simpan file Word tersebut.

- Klik File > Save As (atau Export), lalu ubah pilihan Save as type menjadi PDF (*.pdf).

- Penamaan File: Berikan nama file dengan format Nama_NIM_Kelas (contoh format:

Nama_NIM_Kelas.pdf).

### Langkah 5

Pemeriksaan Akhir & Pengumpulan

- Buka kembali file PDF yang telah dibuat untuk memastikan identitas diri dan tata letak (layout) jawaban sudah rapi dan tidak berantakan.

- Unggah/kumpulkan file PDF tersebut ke link Google Drive yang sudah disediakan sebelum batas waktu akhir pengumpulan, yaitu Sabtu, 12 September 2026 pukul 23.59 WIB.
